📱 ¿Qué es StudyFlow?

StudyFlow es un **ecosistema académico multiplataforma centralizado** diseñado específicamente para el estudiante del siglo XXI. El núcleo dinámico centralizado es una **API REST independiente** conectada a MySQL en la nube, la cual alimenta de forma consistente tres clientes de consumo:

  • Cliente Escritorio (JavaFX): Patrón MVC clásico e hilos asíncronos en Java 17.
  • Cliente Web (PWA): Progressive Web App en Angular con soporte de Service Worker sin caché para entornos offline.
  • Cliente Móvil (Android): App móvil nativa con Material Design 3 y consumo asíncrono robusto mediante Retrofit 2.

🚀 Aspectos Clave de Calidad 2.0

Durante la pre-evaluación del proyecto intermodular, se identificaron incidencias menores de usabilidad, contraste y serialización JSON. En esta versión 2.0, todas han sido resueltas en profundidad:

  • UI Limpia: Sustituidos booleanos planos (TRUE/FALSE) en tablas por badges reactivos formateados (HECHA / SIN HACER).
  • ComboBoxes Limpios: Uso de StringConverter para desvincular Lombok de la interfaz visual en escritorio.
  • Jackson Sólido: Getters y setters anotados con @JsonProperty("isCompleted") y mapeos de fechas flexibles para evitar reinicios de estado.
  • Accesibilidad Visual: Borde indicador con color Pantone en tarjetas de asignatura en lugar de fondos chillones ilegibles.

🚨 Checklist de Incidencias Resueltas (Evaluación)

Cada una de las incidencias reportadas en tu pre-evaluación ha sido resuelta a nivel de producción en el repositorio local:

✓ 1. Visualización de Booleanos en Tablas (Web PWA y Móvil) Corregido
No se muestra el booleano TRUE/FALSE directamente en el frontend. En su lugar, se representan con etiquetas de estado elegantes en negrita: ✓ HECHA en color verde o ✗ SIN HACER en gris.
Loc: api.ts / TaskAdapter.java / item_task.xml
✓ 2. Ocultación de IDs Autoincrementales por Seguridad Corregido
Se removieron las columnas de identificadores primarios (ID) en las tablas visuales de asignaturas, tareas y notas. Esto evita que el usuario tenga que lidiar con IDs técnicos y previene vulnerabilidades de enumeración directa.
Loc: fragment_subject_list.xml / grades.html
✓ 3. Contraste Visual y Usabilidad de Colores Pantone Corregido
Se eliminó el color rosa pastel chillón por defecto. Ahora, las asignaturas se representan mediante bordes indicadores izquierdos de 5px (indicadores Pantone) de colores sólidos, manteniendo el fondo de la tarjeta en tonos oscuros o neutros legibles.
Loc: item_subject.xml / SubjectAdapter.java
✓ 4. ComboBoxes e Invocaciones String de Lombok en JavaFX Corregido
Se solucionó el bug donde los selectores desplegables de escritorio volcaban el toString() completo del objeto Lombok (ej. Subject(id=4, name=...)). Se implementaron celdas personalizadas basadas en StringConverter para mostrar exclusivamente el nombre legible.
Loc: ExamFormController.java / TaskEditActivity.java
✓ 5. Persistencia y Reseteo asimétrico de Jackson en Android Corregido
Se solucionó el bug de Jackson donde el estado de la tarea (checkbox `isCompleted`) volvía a resetearse a `false` al guardar. Se reestructuraron las entidades aplicando deserialización manual mediante @JsonProperty("isCompleted").
Loc: TaskResponseDTO.java / Task.java
✓ 6. Sincronización de Fechas Multiplataforma (Array vs String) Corregido
Se solucionó el fallo donde las tareas del móvil decían "No date" debido a que la API de Spring Boot serializa las fechas locales como arrays numéricos [2026, 5, 24] mientras que Retrofit forzaba un String. Se creó un deserializador elástico de tipos.
Loc: TaskResponseDTO.java / parseDate()

🗄️ Modelo de Base de Datos Relacional (MySQL)

Estudia y explica con precisión las tablas, claves y campos de la persistencia centralizada en nube de Aiven:

TABLE Users PK: userId
userIdINT AUTO_INCREMENT
userNameVARCHAR(50) NOT NULL
emailVARCHAR(50) UNIQUE
passwordHashVARCHAR(100)
registrationDateDATE
TABLE Subjects PK: subjectId
subjectIdINT AUTO_INCREMENT
userIdINT (FK ➔ Users)
nameSubjectVARCHAR(50) NOT NULL
academicYearVARCHAR(20)
colorVARCHAR(7) (Hex)
TABLE Tasks PK: taskId
taskIdINT AUTO_INCREMENT
subjectIdINT (FK ➔ Subjects)
titleVARCHAR(100) NOT NULL
descriptionTaskTEXT
dueDateDATE
priorityVARCHAR(10) CHECK
isCompletedBOOLEAN DEFAULT FALSE
TABLE Grades PK: gradeId
gradeIdINT AUTO_INCREMENT
subjectIdINT (FK ➔ Subjects)
conceptVARCHAR(50)
scoreDOUBLE (0 to 10)
weightDOUBLE (Percentage)

⚙️ Comandos Útiles y Scripts de Compilación

Utiliza esta chuleta interactiva de comandos PowerShell para ejecutar y compilar cada uno de los 4 módulos de StudyFlow:

1. Lógica del Servidor API (Spring Boot)

Para ejecutar el servidor localmente en modo desarrollo:

cd api
.\mvnw.cmd spring-boot:run

Para generar el archivo ejecutable portable JAR:

cd api
.\mvnw.cmd clean package

2. Aplicación de Escritorio (JavaFX)

Para ejecutar el entorno MVC JavaFX en modo de pruebas:

cd desktop
.\mvnw.cmd javafx:run

Para empaquetar el instalador nativo de Windows (EXE/MSI):

cd desktop
.\mvnw.cmd -DskipTests javafx:jpackage

3. Web App Responsiva (Angular PWA)

Para descargar dependencias limpias e iniciar el servidor local de Angular:

cd pwa
npm install ; npm run start

Para compilar el bundle de producción listo para desplegar en Netlify:

cd pwa
npm run build

4. Aplicación Móvil Nativa (Android Gradle)

Para compilar el APK de pruebas (Debug) de forma directa desde consola:

cd android
.\gradlew.bat assembleDebug
